Data Notes

  • The app requests daily aggregated counts, not the full 311 dataset.
  • Daily response rows are JSON objects shaped like { day, complaints }; Socrata returns both values as strings.
  • Complete calendar weeks are used so weekday and weekend averages are comparable.
  • Zero-complaint days are filled locally if the API omits them.
  • No NYC Open Data app token is used. Tokens are optional for higher Socrata rate limits, but should not be hardcoded into client-side code.
  • Complaints are reports to 311; they do not measure actual noise levels or causation.
